# Интерактивный сторителлинг-лендинг (React)

**Пилотный редакционный проект / Data Storytelling**

Интерактивный сторителлинг-лендинг, разработанный для экспериментального редакционного материала в формате дата-сторителлинга.
Проект исследует стоимость «взрослой жизни» в России: рынок труда, аренду жилья и базовые повседневные расходы.

---

## О проекте

Проект разработан как пилотный редакционный лендинг и proof of concept для формата дата-сторителлинга в онлайн-медиа моих знакомых.
Веб-сайт, архитектура приложения, анимации и пользовательский опыт полностью спроектированы и реализованы мной.

Цель проекта — превратить статичные данные и графики в интерактивный пользовательский опыт  
с постепенным погружением в историю по мере прокрутки страницы.

Проект выполнен в формате **data storytelling / scrollytelling**.

---

## Стек технологий

- React
- JavaScript (ES6+)
- CSS
- Intersection Observer API
- Встраивание графиков через Datawrapper
- Vercel (деплой)

> При работе с CSS и анимациями осознанно использовала AI-инструменты  
> как вспомогательный инструмент — для ускорения итераций, подбора решений  
> и рефакторинга кода.

---

## Реализованная логика

- Модальное стартовое окно  
  - управление фокусом  
  - поддержка клавиатурной навигации
- Плавное появление секций при скролле (Intersection Observer)
- Навигация по секциям через pagination dots
- Отслеживание активной секции при прокрутке
- Адаптивная верстка под desktop и mobile
- Доступность:
  - `aria-labels`
  - `role="dialog"`
  - поддержка `prefers-reduced-motion`
  - фокус-стили для интерактивных элементов

## Статус проекта

Проект выполнен в формате пилотной заказной редакционной работы.  
Решение разрабатывалось как пробный формат дата-сторителлинга и концептуальный прототип.

Проект не был запущен в продакшн, однако полностью реализован технически и использовался для тестирования пользовательских сценариев и визуального повествования.
