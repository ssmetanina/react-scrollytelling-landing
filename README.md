# Интерактивный сторителлинг-лендинг (React)

**Пилотный редакционный проект / Data Storytelling**

Интерактивный лендинг с прокруткой и визуальным повествованием, разработанный в рамках
пилотного редакционного проекта для онлайн-медиа.
Проект посвящён исследованию стоимости «взрослой жизни» в России:
рынка труда, аренды жилья и базовых повседневных расходов.

---

## О проекте

Проект реализован как **пилотный заказной лендинг** и *proof of concept* формата
дата-сторителлинга для цифрового медиа.

Я отвечала за:
- архитектуру фронтенд-приложения
- реализацию пользовательского сценария
- анимации и взаимодействие при скролле
- адаптивную верстку и доступность

Цель проекта — превратить статичные данные и графики
в **интерактивный пользовательский опыт**
с постепенным погружением в историю по мере прокрутки страницы.

Проект выполнен в формате **data storytelling / scrollytelling**.

---

## Стек технологий

- React
- JavaScript (ES6+)
- CSS (без UI-фреймворков)
- Intersection Observer API
- Встраивание графиков через Datawrapper
- Vercel (деплой)

При работе с CSS и анимациями использовала AI-инструменты
как вспомогательный инструмент для ускорения итераций,
поиска решений и рефакторинга кода.

---

## Реализованная функциональность

- Стартовое модальное окно  
  — управление фокусом  
  — поддержка клавиатурной навигации  

- Плавное появление секций при прокрутке  
  (Intersection Observer API)

- Навигация по секциям через pagination dots

- Определение активной секции при скролле

- Адаптивная верстка под desktop и mobile

- Доступность:
  - `aria-label`
  - `role="dialog"`
  - поддержка `prefers-reduced-motion`
  - фокус-стили для интерактивных элементов

## Статус проекта

Проект выполнен в формате **пилотной заказной редакционной разработки**.

Решение создавалось как пробный формат дата-сторителлинга
и концептуальный прототип для тестирования пользовательских сценариев,
визуального повествования и взаимодействия с данными.

Проект не был запущен в продакшн,
однако полностью реализован технически
и использовался для демонстрации формата и оценки UX-решений.
